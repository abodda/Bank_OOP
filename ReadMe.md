# Bank_OOP Project 🎉

Welcome to the **Bank_OOP** project! This repository contains a comprehensive bank management system implemented using Object-Oriented Programming principles in C++. 🏦

## Features ✨
- **User Management**: Secure login with a maximum of 3 attempts.
- **Account Operations**: Create, update, and delete client accounts.
- **Currency Exchange**: Integrated screens for currency exchange operations.
- **Permissions**: Different user permissions for various banking operations.

## Installation 📥
1. **Clone the repository**:
   ```bash
   git clone https://github.com/abodda/Bank_OOP.git
2. Navigate to the project directory:
cd Bank_OOP
3. Compile the project:
g++ -o bank_app main.cpp
4. Run the application:
./bank_app 
## Usage 🚀
1. Login: Use your credentials to log in. You have 3 attempts.
2. Manage Accounts: Create, update, or delete client accounts.
3. Currency Exchange: Access the currency exchange feature from the main menu.
